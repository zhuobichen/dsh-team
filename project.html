DeepSeek Harness 插件 TypeScript MIT License GitHub →

这是什么

dsh-team 是一个 DeepSeek Harness（dsh）插件：注册一套「协调 → 分析 → 编码 → 评审 → 测试」的团队角色 skill，让 agent 遇到复杂任务时自动按角色接力完成，而不是单枪匹马硬扛。

它解决一个普遍痛点：单个 agent 面对多模块、多步骤的复杂任务时，容易顾此失彼、上下文膨胀、质量不可控。团队接力把任务拆解、分工、层层把关，每个环节都有专门的 agent 负责。

起源 · 结合已有项目

这个插件的设计源于我的 MathModeling-Agent 项目——一个 5 角色（建模 / 编码 / 解析 / 评审 / 写作）协作的数学建模多 Agent 系统。

我把其中的多 Agent 编排经验抽离、通用化，做成了任何复杂任务都能用的 DSH 技能包：

  • MathModeling-Agent 的「Parser + Modeler」→ 通用化为 analyst
  • 「Coder」→ coder
  • 「Reviewer」→ reviewer
  • 「验证/评估」→ tester
  • 「Workflow 编排」→ team-lead + team-workflow

团队角色

🎯

team-lead

协调者：分解任务、委派角色、汇总最终交付。团队接力的起点和终点。
🔍

analyst

分析者：理解需求、调研现状、设计可执行的实现方案。
⌨️

coder

编码者：按方案实现代码，自测通过后交给评审。
🔎

reviewer

评审者：正确性、完整性、可维护性、安全性四维把关。
🧪

tester

测试者：真实场景验证、边界测试、回归确认。
🔗

team-workflow

接力工作流：角色分工、委派方式、评审/测试闭环规范。

接力流程

🎯 team-lead → 🔍 analyst → ⌨️ coder → 🔎 reviewer → 🧪 tester → 🎯 team-lead 汇总
  • 上一个角色的输出是下一个角色的输入
  • reviewer 发现问题 → 回给 coder → 再评审
  • tester 验证不通过 → 回给 coder → 再测试
  • team-lead 汇总所有产出，形成最终交付

安装使用

安装：

dsh plugin --profile web add dsh-team

技术栈

  • DeepSeek Harness（dsh）—— 插件运行时，基于「一切皆插件」的 cordis 框架
  • Skill 机制 —— 通过 skill registry 注册角色规范（SKILL.md）
  • Subagent 能力 —— 角色接力基于 DSH 的 subagent 委派
  • TypeScript —— 插件实现语言
